# Практика дня 1 — массивы и срезы

Выполняется в занятии дня 2: повторение и закрепление темы дня 1.
Каждый пример хранится в отдельной папке exercise-NN; следующие папки создаются по мере выдачи заданий.

## Пример 1

Код: `exercise-01/main.go`.

1. Создай массив из четырёх любых int и срез s первых двух элементов.
2. Скопируй значение s в t.
3. Добавь один элемент к t через append.
4. Выведи массив, оба среза, их длины и ёмкости.

До запуска пришли наставнику код и свой прогноз вывода. Текущий этап — самостоятельное написание кода; решение не предоставлено.

После проверки прогноза запуск из этой папки:

```powershell
go run ./exercise-01
```

## Пример 2 — добавление при недостаточной ёмкости

Код: `exercise-02/main.go`.

1. Создай массив из трёх любых int и срез s всего массива.
2. Скопируй значение s в t.
3. Добавь один элемент к t через append, затем измени t[0].
4. Выведи массив, s, t и длины обоих срезов.

До запуска пришли код, прогноз вывода и объяснение того, какие переменные используют общий массив после append. Точную новую ёмкость предсказывать не нужно.

## Пример 3 — copy и длина назначения

Код: `exercise-03/main.go`.

1. Создай src из трёх разных int и отдельный dst через make с длиной 2 и ёмкостью 5.
2. Скопируй элементы src в dst через copy, сохрани число скопированных элементов.
3. Измени src[0].
4. Выведи src, dst, число скопированных элементов, len(dst) и cap(dst).

До запуска пришли прогноз (можно в комментариях) и объясни, чем ограничено число скопированных элементов.

## Пример 4 — уменьшение и восстановление длины

Код: `exercise-04/main.go`.

1. Создай массив из пяти разных int и срез s с индексами исходного массива от 1 до 3 включительно.
2. Уменьши длину s до одного элемента изменением границ.
3. Восстанови длину s до трёх элементов изменением границ, без append и copy.
4. Измени s[2]. Выведи исходный массив, s, len(s) и cap(s).

До запуска запиши прогноз содержимого s после каждого изменения границ и итогового вывода.
