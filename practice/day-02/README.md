# Практика дня 2 — указатели и передача по значению

## Пример 1 из 5

Код: `exercise-01/main.go`.

1. Напиши две функции без возвращаемого значения: первая принимает int и увеличивает параметр на 5; вторая принимает *int и увеличивает число по адресу на 5.
2. В main создай число 10. Вызови первую функцию и выведи число, затем вызови вторую и снова выведи число.
3. До запуска запиши прогноз вывода и объясни различие результатов.

После проверки прогноза запуск из этой папки: `go run ./exercise-01`.

## Пример 2 из 5 — обмен значений через указатели

Код: `exercise-02/main.go`.

Напиши функцию Swap, принимающую два *int и меняющую местами значения исходных переменных. Функция ничего не возвращает.

В main создай две переменные с разными значениями, вызови Swap и выведи обе переменные. До запуска запиши прогноз и объясни, что именно меняется: адреса в параметрах или значения по адресам. Считай указатели ненулевыми.

## Пример 3 из 5 — переназначение локального указателя

Код: `exercise-03/main.go`.

Напиши функцию Redirect с двумя параметрами *int, без результата. Внутри переназначь первый параметр так, чтобы он хранил тот же адрес, что второй. Затем запиши 99 через первый параметр.

В main создай x=10, y=20 и указатель p на x. Передай в Redirect значение p и адрес y. После вызова выведи x, y и значение по адресу p. До запуска запиши прогноз и объясни, куда указывают p в main и первый параметр функции после переназначения.

## Пример 4 из 5 — методы структуры

Код: `exercise-04/main.go`.

Создай структуру Player с полем Score типа int. Напиши два метода без результата: AddValue с value receiver и AddPointer с pointer receiver. Каждый метод должен увеличивать поле Score своего receiver на 5.

В main создай Player со Score=10, вызови AddValue и выведи Score, затем на той же переменной вызови AddPointer и снова выведи Score. До запуска запиши прогноз и объясни различие результатов.

## Пример 5 из 5 — переназначение pointer receiver

Код: `exercise-05/main.go`.

Создай Player с полем Score int и метод Experiment с pointer receiver, без результата. В методе создай отдельную локальную структуру Player со Score=50, переназначь receiver на её адрес, затем через receiver установи Score=99. Выведи Score через receiver внутри метода.

В main создай исходного игрока со Score=10, вызови Experiment и выведи Score исходного игрока после вызова. До запуска запиши прогноз обеих строк и объясни, какую структуру меняет метод после переназначения receiver. Это учебный эксперимент с локальным указателем.
