## Пройденная теория и проверенные ответы

### Массивы и срезы

Для:

```go
a := []int{1, 2, 3, 4}
s := a[1:3]
t := append(s, 9)
t[0] = 7
```

Правильный результат:

```text
a = [1 7 3 9]
s = [7 3]
t = [7 3 9]
```

До `append`:

```text
len(s) = 2
cap(s) = 3
```

Новый массив не создаётся, потому что новая длина 3 помещается в `cap=3`.

Также закреплено:

* при присваивании массива копируются элементы;
* `[3]int` и `[4]int` — разные типы;
* при присваивании среза копируется его описатель;
* срезы могут использовать общий базовый массив;
* длина среза не входит в тип `[]int`;
* результат `append` нужно присваивать обратно, поскольку он возвращает новый описатель с обновлённой длиной;
* `copy` копирует `min(len(dst), len(src))` элементов и не увеличивает длину назначения;
* nil-срез имеет `len=0`, `cap=0`, сравнивается с nil и поддерживает `append`.

### Map

Закреплено:

* zero value map — nil;
* чтение из nil map безопасно;
* отсутствующий ключ возвращает zero value типа значения;
* `len(nilMap) == 0`;
* `delete` для nil map безопасен;
* запись в nil map вызывает panic;
* пустая созданная через `make` map допускает запись;
* существование ключа проверяется через comma-ok:

```go
value, ok := m[key]
```

Если значение не нужно:

```go
_, ok := m[key]
```

Для:

```go
m := map[string]int{"ready": 0}
```

Результаты:

```text
m["ready"]   -> 0, true
m["missing"] -> 0, false
```

После `delete(m, "ready")`:

```text
m["ready"] -> 0, false
```

При присваивании map копируется дескриптор общей runtime-структуры. Изменения через вторую переменную видны через первую.

Допустимые ключи:

* `string` — да;
* `[2]int` — да;
* структура из `string` и `int` — да;
* `[]byte` — нет;
* `func()` — нет.

Ключ должен быть сравнимым.

Порядок `range` по map не гарантируется. Для детерминированного вывода:

1. Собрать ключи в срез.
2. Отсортировать ключи.
3. Пройти по отсортированным ключам и получать значения из map.

Сложности:

```text
Time: O(n log n)
Space: O(n)
```

### Строки и Unicode

Для:

```go
s := "A😊"
```

Правильно:

```text
len(s) = 5
len([]rune(s)) = 2
```

`range` выдаёт байтовые индексы `0` и `1`.

`s[1]` имеет тип `byte` (`uint8`) и возвращает только первый байт UTF-8-кодировки эмодзи, а не всю эмодзи.

Для:

```go
s := "кот"
r := []rune(s)
r[0] = 'р'
```

Результат:

```text
s         = "кот"
string(r) = "рот"
len(s)    = 6
len(r)    = 3
```

Строка неизменяема. `[]rune(s)` создаёт отдельный срез Unicode-кодовых точек.

Для получения первого Unicode-символа нельзя использовать только `s[0]`:

* на пустой строке будет panic;
* для многобайтовой буквы вернётся один byte;
* нужно проверить пустой ввод и использовать `[]rune`, `range` или функции `utf8`.

### `practice/day-03/exercise-01/main.go`

```go
package main

func main() {
}

func wordFrequency(words []string) map[string]int {
	mmap := make(map[string]int)

	if len(words) == 0 {
		return mmap
	}

	for _, v := range words {
		mmap[v]++
	}

	return mmap
}
```

Сложности:

```text
Time: O(n)
Space: O(k), где k — число уникальных строк
Worst-case Space: O(n)
```

Проверить:

```go
[]string{"go", "map", "go", "", "map", "go"}
```

Ожидаемые пары:

```text
""    -> 1
"go"  -> 3
"map" -> 2
```

Также проверить nil и пустой срез. Результат должен быть созданной пустой map, не nil.

### `practice/day-03/exercise-02/main.go`

```go
package main

func main() {
}

type User struct {
	Name       string
	Department string
}

func groupByDepartment(users []User) map[string][]string {
	mmap := make(map[string][]string)

	if len(users) == 0 {
		return mmap
	}

	for _, u := range users {
		mmap[u.Department] = append(mmap[u.Department], u.Name)
	}

	return mmap
}
```

Сложности:

```text
Time: O(n)
Space: O(n)
```

Проверить:

```text
Ann — backend
Bob — frontend
Cat — backend
Dan — ""
```

Ожидаемый результат:

```text
backend -> ["Ann", "Cat"]
frontend -> ["Bob"]
"" -> ["Dan"]
```

Порядок имён внутри группы должен совпадать с входным порядком.
