## Результаты и ошибки

- Recall: верно объяснены порядок `WaitGroup.Add` и `Done`, receive из закрытого пустого канала и назначение race detector. Закреплены: `range` по закрытому пустому каналу завершается без нулевого значения; upgrade `RLock` → `Lock` приводит к deadlock.
- Создана гонка `counter++` из 100 goroutine; `go run -race main.go` показал read/write и write/write conflicts. Исправление через `sync.Mutex` проверено: `gofmt` и `go vet` чисты, `go run -race main.go` вывел `100` без диагностик.
- Намеренный deadlock небуферизованного канала в одной goroutine проверен: runtime сообщил `all goroutines are asleep - deadlock!`. Ученик объяснил отсутствие одновременного receiver.
- Уточнено: `go vet` проверяет статические подозрительные конструкции, включая copylocks; он не находит каналные deadlock и нарушения pipeline. `-race` зависит от реально выполненного сценария.
