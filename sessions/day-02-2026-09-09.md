Теория: в Go аргументы передаются по значению. Параметр int получает копию числа, параметр *int — копию адреса. Изменение значения по скопированному адресу затрагивает исходную переменную; это не передача самой переменной по ссылке.

```go
    n = 40

func main() {

    b := 20
    change(a, &b)
    fmt.Println(a, b)
}
```

## Pass-by-value — первый ответ верен; переназначение указателя

Ученик верно предсказал `10 50` и объяснил изменение копии a и оригинальной b через адрес. Формулировка «передали копию и ссылку» уточнена: Go в обоих случаях копирует значение аргумента, для *int это адрес. Ответ по поведению верен без дополнительных подсказок к примеру; код не запускался.

Следующий теоретический шаг: `*p = ...` меняет значение по адресу, а `p = ...` меняет адрес в локальном параметре p.

```go

func main() {

    change(&x)
    fmt.Println(x)
}
```
