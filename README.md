# Подготовка к Avito Backend Go

Экономный режим: основная модель **Terra Medium**, для сложных проверок и mock — **Sol Medium**. Распределение по дням и этапам: [MODEL_GUIDE.md](MODEL_GUIDE.md). Модель выбирается в интерфейсе; наставник сообщает, когда стоит её сменить.

## Синхронизация через GitHub

Репозиторий: https://github.com/nikooov4/studying.git

На другом компьютере один раз выполни:

```sh
git clone https://github.com/nikooov4/studying.git
cd studying
```

Открой эту папку в IDE и начни новый диалог с обычной фразы ниже. Для отправки изменений нужна авторизация GitHub на этом компьютере. В репозитории сохраняются код и учебные записи; точка продолжения находится в `CURRENT.md`.

После каждого учебного дня наставник сохраняет прогресс, делает коммит и push. Для промежуточного сохранения напиши «Сохрани прогресс, сделай коммит и push». Перед переходом на другой ПК дождись подтверждения успешной отправки. В начале следующего занятия наставник проверяет обновления; при чистом рабочем дереве подтягивает их через `git pull --ff-only`.

## Начало занятия

Каждый учебный день начинай в новом диалоге, открытом в этой папке:

> Начинаем день N. Следуй STUDY_PLAN.md и AGENTS.md. Не переходи к следующему этапу, пока я не выполню текущий. Не пиши решения практических заданий вместо меня.

Наставник сначала читает сохранённый прогресс. В конце можно написать «Завершаем день, сохрани прогресс», а при перерыве — «Останавливаемся здесь, сохрани текущий этап». Номер дня означает день учебного плана; незавершённый день можно продолжать на другую дату.

| Путь | Назначение |
|---|---|
| `AGENTS.md` | Правила наставника и сохранения прогресса |
| `STUDY_PLAN.md` | Основной учебный план на 63 дня |
| `CURRENT.md` | Текущее состояние и точка продолжения |
| `avito_progress_tracker.csv` | История попыток алгоритмических задач |
| `sessions/` | Итоги занятий, ошибки, оценки и повторения |
| `algorithms/` | Самостоятельные решения алгоритмов на Go |
| `practice/` | Упражнения по дням: Go, SQL и другие темы |
| `projects/` | Самостоятельные тестовые проекты |
| `archive/codex_avito_mentor_prompt.md` | Исходный промпт для справки |

Шаблон отчёта: `sessions/TEMPLATE.md`. Оценки и статусы появляются по результатам занятий; пустой трекер не означает нулевой уровень знаний.
